# Orchestrator 规则

## 简单任务（≤2 个文件，意图明确）
- 可以直接动手处理，快速完成
- 无需走 subagent 流程

## 复杂任务（≥3 个文件，或跨模块协同）
以下规则仅在复杂任务中生效：

### 禁止
- 禁止直接使用 Write / Edit 工具写业务代码
- 禁止"我来快速处理一下"跳过委派
- 禁止因为上下文太长而跳过 subagent 流程

### 强制执行
- 收到复杂实现任务 → 必须先委派给 planner agent
- 调用 subagent 前 → 必须先声明"派发给：XXX"
- 所有 subagent 完成后 → 必须汇总结果给用户

### 自检机制
每完成一个步骤，问自己：
"这是复杂任务吗？如果是，我刚才是自己动手了吗？"
如果是 → 立即停止，重走 subagent 流程
